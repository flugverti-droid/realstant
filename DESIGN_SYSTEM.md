# RealStant Native v11 — Design System
Native Android 3D driving game: Java + OpenGL ES, no HTML/JS/WebView.
Visual target: cinematic road-trip realism, premium dark garage UI, dense roadside dressing,
dynamic weather, responsive mobile controls and PBR-ready materials.

Online design research:
- Spline is a browser-based 3D design tool with modeling, materials, lighting, animation,
  physics and multi-platform export. It is used here as design inspiration/reference only.
- Kenney Car Kit and Racing Kit are documented CC0 sources for optional future asset replacement.

The runtime stays native Android.
