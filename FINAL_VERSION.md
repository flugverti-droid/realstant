# RealStant — Final Game Build

Это финальная игровая сборка нативной Android 3D-игры про аркадный stunt park.

## Игровой цикл
- Главное меню
- Выбор транспорта
- Stunt Park
- Свободная езда
- Прыжки и воздушные игровые трюки
- Система очков и combo
- Чистое приземление и бонусы
- Несколько камер
- Переключение транспорта
- Гараж и прогресс
- Настраиваемое управление
- Разные игровые карты и режимы

## Транспорт
- BMX
- PITBIKE
- SCOOTER
- MTB

## Stunt Park
Большая нативная 3D-площадка с рампами, quarter-pipe, трамплинами, платформами, боксами, rails и отдельными зонами для разных типов транспорта.

## Графика
OpenGL ES 3, depth testing, lighting, fog, материалы, процедурные 3D-модели, частицы, погодные эффекты, день/ночь и оптимизация под мобильные устройства.

## Технически
- Java + OpenGL ES 3
- Android minSdk 26
- compileSdk 35
- Gradle 8.11.1
- Android Gradle Plugin 8.10.1
- JDK 17
- Без HTML, JavaScript и WebView

Игровые трюки являются виртуальной аркадной механикой и не являются инструкциями для повторения в реальной жизни.
