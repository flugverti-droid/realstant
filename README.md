# RealStant

Native Android 3D arcade racing game.

## Included
- Landscape-first Android UI.
- Multiple rideable transport categories: BMX-style bicycle, scooters, bikes and quad.
- Separate maps with different environments and weather.
- Garage/progression configuration.
- Custom control profiles.
- Camera modes.
- Native Java + OpenGL ES 3 renderer.
- Score, time-trial and arcade event systems.
- GitHub Actions APK build with Java 17, Gradle 8.11.1 and AGP 8.10.1.

The gameplay is intentionally arcade/fantasy. It does not provide instructions for
performing dangerous real-world stunts.


## Stunt Park update
- Dedicated stunt plaza with ramps, quarter-pipe style structures, rails, boxes, decks and landing zones.
- Playable arcade transport rotation: BMX, PITBIKE, SCOOTER, MTB.
- Ramp-triggered airtime, jump arc, spin input, trick combo scoring and landing bonus.
- HUD vehicle switch and camera switch.
- All stunts are fictional in-game mechanics; no real-world stunt instructions are included.
