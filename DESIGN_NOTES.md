# RealStant Native v10

Полноценный нативный каркас мобильной 3D-игры на Java + OpenGL ES 3.

## В игре
- свободная езда;
- несколько машин и классов;
- 4 трассы;
- дождь, снег, туман;
- гараж и улучшения;
- сохранение профиля;
- чекпоинты и таймер;
- HUD и удобные зоны управления;
- система достижений;
- процедурный мир.

## 3D-ассет
Проект содержит описание интеграции CC0 Toy Car из Khronos glTF Sample Assets. Сам архив сборки может быть дополнен бинарным GLB при наличии сетевого доступа к исходному репозиторию.
